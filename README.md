# Runverve Metrics API

A FastAPI-based backend system to fetch and store user metrics such as hydration, fatigue, and posture from Runverve wearable devices into a central SQLite database.

---

##  Features

1.User registration & login (token-based authentication)
1. User profile view
3. device storage
4. Metrics retrieval by user/device
5. SQLite + SQLModel (built on SQLAlchemy & Pydantic)
6.Swagger/OpenAPI documentation at `/docs`
7.JWT Authentication

## Tech Stack
1.Python
2.FastAPI
